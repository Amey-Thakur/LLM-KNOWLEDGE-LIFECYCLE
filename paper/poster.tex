\begin{columns}
    \column{0.5}
    \block{1. The Fragmentation Problem}{
        LLM knowledge management is siloed into subfields: RAG, knowledge editing, continual learning, context engineering, and agent memory. Each is optimized in isolation, and systems fail at the \textbf{boundaries}.
        \begin{itemize}
            \item \textbf{Issue:} No unified formalism for the life of a fact.
            \item \textbf{Evidence:} Across 20 representative works, median lifecycle coverage is 2 of 5 stages.
        \end{itemize}
    }

    \block{2. The Knowledge Lifecycle Framework}{
        \centering
        \begin{tikzpicture}[scale=1.5]
            \node[draw, rounded corners, fill=blue!10, minimum width=3cm] (acq) at (0,3) {1. Acquisition};
            \node[draw, rounded corners, fill=teal!10, minimum width=3cm] (sto) at (3,1) {2. Storage};
            \node[draw, rounded corners, fill=orange!10, minimum width=3cm] (ret) at (1.5,-2) {3. Retrieval};
            \node[draw, rounded corners, fill=red!10, minimum width=3cm] (upd) at (-1.5,-2) {4. Update};
            \node[draw, rounded corners, fill=purple!10, minimum width=3cm] (fgt) at (-3,1) {5. Forget};

            \draw[->, line width=2pt] (acq) -- (sto);
            \draw[->, line width=2pt] (sto) -- (ret);
            \draw[->, line width=2pt] (ret) -- (upd);
            \draw[->, line width=2pt] (upd) -- (fgt);
            \draw[->, line width=2pt] (fgt) -- (acq);
        \end{tikzpicture}
        \vspace{1cm}
        Five structural stages: Acquisition, Storage, Retrieval, Update, and Forgetting. The interactions between stages are where deployed systems fail.
    }

    \column{0.5}
    \block{3. Metric: Lifecycle Desynchronization ($\mathcal{D}_{sync}$)}{
        The divergence between a synchronized system's output and the deployed system's output. For a fact with verified answer $y^*$, it reduces to a surprisal:
        \begin{equation*}
            \widehat{\mathcal{D}}_{sync} = -\ln P\!\left(y^* \mid q,\, \theta_{stale},\, \mathcal{M}_{now}\right)
        \end{equation*}
        A value of $n$ nats means the correct answer holds probability $e^{-n}$. Above $9.2$ nats, no realistic decoding recovers it.
    }

    \block{4. Intervention: The Provenance Vector ($p$)}{
        \begin{itemize}
            \item \textbf{Mechanism:} each FFN memory slot $(k_i, v_i)$ gains metadata $p_i$ encoding acquisition time and source reliability.
            \item \textbf{Gating:} stale activations are attenuated at inference; weights are never modified.
        \end{itemize}
        \centering
        \begin{equation*}
            S(\Delta \tau_i) = \sigma(\gamma - \beta \cdot \Delta \tau_i)
        \end{equation*}
        Fresh facts pass ($S \approx 1$); outdated facts are muted ($S \to 0$).
    }

    \block{5. Measurement: Vioxx Withdrawal on GPT-2}{
        Vioxx was withdrawn in 2004. With the withdrawal notice \textbf{in context}, GPT-2 still answers ``safe.''
        \begin{itemize}
            \item $P(\text{``safe''})$: 37.5\% without context, \textbf{42.6\% with} the withdrawal notice.
            \item $P(\text{``withdrawn''})$: $5.9 \times 10^{-6}$, so $\widehat{\mathcal{D}}_{sync} = 12.05$ nats.
            \item Context shifts the full output distribution by only $0.03$ nats: retrieval works, resolution fails.
        \end{itemize}
        Fully reproducible: deterministic script in the repository.
    }

    \block{6. Conclusion}{
        Knowledge conflicts are measurable, and their root cause is metadata-free parametric storage. The Knowledge Lifecycle framework names the stages, $\mathcal{D}_{sync}$ measures the boundary failures, and the Provenance Vector offers an architectural path to closing them.
    }
\end{columns}
