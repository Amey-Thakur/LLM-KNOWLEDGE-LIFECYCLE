# Vendored typeface

`inter-variable.woff2` is the Latin subset of the Inter variable font, covered
by the **SIL Open Font License, Version 1.1**, which permits bundling and
redistribution inside a project provided the font is not sold on its own and
the licence travels with it.

| File | Family | Designer | Source | Licence |
|------|--------|----------|--------|---------|
| `inter-variable.woff2` | Inter | Rasmus Andersson | [Google Fonts](https://fonts.google.com/specimen/Inter) | [OFL 1.1](https://openfontlicense.org/) |

## Why it is stored here

The video and GIFs are rendered both on a maintainer's machine and on a GitHub
Actions runner. Shipping the font with the renderer is what makes the two
produce the same frames: neither depends on which typefaces the operating
system happens to have installed.
